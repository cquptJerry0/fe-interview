# tracker 主表

`tracker` 是这个仓库的唯一状态表区域。

目标不是写日报，而是维护秋招上场系统里每个条目的最小状态。

## 真源原则

- 仓库里的 [master.csv](master.csv) 是唯一真源。
- 飞书表只做同步视图，不再单独维护另一套正文或另一套状态体系。

## 当前飞书表

- 多维表格名称：`秋招上场系统总表`
- 链接：[秋招上场系统总表](https://bytedance.larkoffice.com/base/FrLCbdR18au0UusU61Dclghmnsb)
- 当前视图：`总表`、`八股`、`手写`、`项目`

## 最简字段

```text
线别 | 模块 | 条目 | 状态 | 最少关键词 | 下一步 | Git文件
```

字段说明：

- `线别`：八股 / 手写 / 项目
- `模块`：JavaScript、浏览器、React、AI 项目等
- `条目`：具体问题、题型或项目追问
- `状态`：未上场 / 可上场
- `最少关键词`：复习时用于快速唤醒回答骨架的 3 到 6 个词
- `下一步`：下一次实际动作
- `Git文件`：对应正文内容文件，放最后一列便于直接跳转

## 使用原则

1. 只维护主系统条目，不维护 raw 原材料条目。
2. 新增正文文件时，顺手补一行到 `master.csv`。
3. 条目真正能稳定回答、手写或讲述后，再改成 `可上场`。
4. 飞书里只保留这一张总表，再按 `线别` 建三个视图。
5. `最少关键词` 不是完整答案，只是最小复习触发器。
