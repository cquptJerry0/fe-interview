# .ai

这里不再放一堆 playbook / capability / policy。

`.ai/` 现在只保留 4 类东西：

- 流程：怎么从面经输入走到训练、建档、归档
- 规则：单题回答、编程题、归档和统一质量门槛
- 模板：真正会被复用的少量模板
- 路径与 tag：路径别名、tag 词表

## 建议阅读顺序

1. `01-训练总流程.md`
2. `02-单题SOP.md`
3. `03-编程题SOP.md`
4. `04-归档与画像SOP.md`
5. `05-统一规则.md`

## 目录说明

- `runtime/paths.yaml`：仓库路径别名
- `schemas/tags.yaml`：统一 tag 词表
- `templates/`：少量高频模板

原则：少文件、少跳转、少重复。
