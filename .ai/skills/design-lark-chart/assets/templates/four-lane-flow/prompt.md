# 四通道技术流程图提示词模板

将本模板中的业务输入替换为当前任务的真实资料。不要照抄案例里的发布产品、站点或认证身份。仅当用户希望同时表达流程与依赖时使用四通道。

```text
请在用户指定的飞书画板中绘制一张可编辑的技术流程与依赖图。

推进方式：
先判断当前已有的是想法、骨架还是待修改的成图，不从头重做。
按五步推进：定主题 → 搭骨架 → 填内容 → 展开细节 → 整体优化。
定主题先说明给谁看、主要体现什么、让读者理解什么以及本图范围。
骨架包含内容区域、位置与阅读方向、颜色含义、图形与图标含义，
同时画清主要关系。结构确认后，成批补完整主流程，再展开必要机制，
最后检查讲解顺序、文案、字体和连线。
先按 Skill 入口匹配最相关好案例并查看真实预览、读取说明，准备绘制时读源码。
按“设计说明、视觉定义、一张完整 ASCII”交付：分区名/色值、组件与线型图例、
完整主链、必要支路、平台/数据/调用在同一张图内，不拆给用户自己拼。
大图保留独立加粗整图标题、原生分区标题、区内服务名；图例集中顶部，
中文用途和必要技术名在节点内部，不悬挂小字；队列水平圆柱、数据库竖直圆柱。
用户已确认的内容不重复询问，不逐节点请求批准。
若明确要求直接完成，可按这个顺序连续执行，不增加固定审批轮次。
局部反馈只改相关区域，保留已有颜色、布局和用户手工修改。
若本轮只要 ASCII + prompt，不写入飞书；若只要骨架，不提前画满细节。

业务输入：
图要回答的问题：填写读者看完应理解的因果关系。
横向业务阶段：填写真实阶段及边界。
完整主步骤：逐个填写“执行主体：具体动作”，不要只写抽象名称。
需要展开的机制：填写确有必要解释的计算、判断、等待或恢复流程。
平台与数据：填写目标平台、Runner、共享记录、制品及其读写关系。
认证：填写使用者、身份类型和用途，不提供凭据值。
已核实资料：填写源码或文档依据，并列出仍未知的事实。
当前进度与本轮范围：填写已有版本、已认可内容和这轮要改的区域。
目标画板与覆盖范围：由本次用户授权确定，不复用案例 token。

结构：
从左到右推进业务；从上到下使用四条水平通道：
1. 细节展开：局部小流程，虚线框包围，并关联对应主节点。
2. 主流程：步骤完整，节点采用“主体：动作”。
3. 平台：平台服务、执行环境、与节点有关系的数据和制品。
4. 认证：独立展示凭据 / 身份，以有名称的关系关联使用方。

同一流程不可折行向下续接。若确有两个独立任务，可在主流程通道
内使用两个水平基线，但必须画清“同时触发”和“等待成功”的区别。
子流程用来解释必要机制，不能替代主流程的必经步骤。
没有平台或认证依赖的地方留白，不凑满网格。

视觉：
默认使用飞书原生组件，不重新进行 DSL、代码图、SVG 三选一。
DSL 只是批量构建的中间格式；最终节点正文与连接线需保持可编辑。
使用原生矩形、胶囊、菱形、分栏平台框、圆柱、平行四边形、
折角文件等组件。图例中每种形状必须与正文的对象类型一致。
横向阶段使用少量浅色背景与清晰标题；颜色表示阶段，形状表示角色。
主节点正文通常两到三行，主体与动作读起来像人在讲解。
平台用正式名称，数据说清代表什么；缩写先翻译成作用或动作。
不使用 C1 / C2，不放两大块补充说明，不加无关代码路径映射。

留白与走线：
按最长文字和实际图形内接区计算宽高，不把 fit-content 当作原生
菱形、胶囊或平行四边形不会截字的保证。
节点、阶段、线标签都要留空间；“触发”不能挤在两个框之间。
主线用实线箭头，展开与依赖用带含义的虚线。没有真实合流就不共线。
所有连接端点绑定节点，所有主体文字保留在原生节点内。

交付：
按本轮范围交付，不把骨架或本地稿说成远端终稿。
实际更新画板时先回读和备份，保留用户修改，做 dry-run 后按授权更新。
写入后回读并检查真实导图，修正文案换行、标签遮挡和连线歧义。
只汇报真正检查过的内容，不把静态检查通过当成视觉验收完成。
```

布局草图只约束关系，不固定节点数量：

```text
                 阶段一                  阶段二                   阶段三
细节展开      [必要的小流程]           [必要的小流程]            [必要的小流程]
                    :                       :                        :
主流程        [主体：动作] --------> [主体：动作] ---------> [主体：动作]
                    :                       :                        :
平台          [平台 / 数据]           [平台 / 制品]             [平台 / 数据]
                    :                       :                        :
认证          [使用的身份]            [使用的身份]              [使用的身份]
```

复用后需要重新核实每条关系。不同项目不一定需要全部通道或同一套阶段色。
