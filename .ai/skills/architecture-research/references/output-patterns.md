## 4. 文档职责

```markdown
| 文档 | 所属层 | 唯一回答的问题 | 权威内容 | 不包含 |
|---|---|---|---|---|
| README | 入口 | 从哪里开始 | 导航 | 知识正文 |
| 总纲 | 稳定结构 | 完整体系是什么 | 唯一定义 | 状态日志 |
| 进度 | 动态状态 | 当前掌握到哪里 | 状态和证据 | 机制解释 |
```

配套引用关系：

```text
README
  ├── 稳定主干
  ├── 动态状态
  └── 生成视图
```
