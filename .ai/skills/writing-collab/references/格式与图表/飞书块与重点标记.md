# 飞书块与重点标记

用于飞书文章的阅读组织。内容结构先于平台装饰；授权写正文不自动授权编辑线上文档。

## 按阅读任务使用

- 标题层级承担导航，不能仅靠字号、颜色或加粗模拟章节关系。
- 高亮块适合必须注意的限制、风险或关键判断。整篇到处高亮会削弱重点。
- 引用块用于来源陈述或明确引文，并保留归属；不要把普通结论包装成权威引用。
- 分栏只在并排内容确有对照或独立阅读价值时考虑；窄屏阅读和导出可能破坏关系。
- 折叠适合可选详情，不应隐藏前置条件、核心证据、风险或成功标志。
- 局部重点标记只标识读者需要抓住的对象或结论。颜色不能成为唯一信息载体。

## Markdown 与原生格式

用户要求可迁移 Markdown 时，标题、列表、表格沿用标准语法；难以表达的分栏、高亮或图片占位采用明确的起止标记。先统一标记含义，再按授权转换到平台原生格式，不把格式说明混进正式正文。

以下为用户选用蓝色强调时的一组可选约定，不是所有文种的固定配色：

| Markdown 标记 | 飞书目标形式 |
|---|---|
| `【蓝色加粗：重点】` | 蓝色与加粗同时生效的行内重点 |
| `【蓝色高亮块】` 至 `【/蓝色高亮块】` | 蓝色高亮块，内部可放短段或分点 |
| `【双栏】`、`【左栏】`、`【右栏】`、`【/双栏】` | 两列分栏 |
| `【画板占位】` 至 `【/画板占位】` | 图类型、范围与节点说明，保留插入位置 |
| `【截图占位】` 至 `【/截图占位】` | 独立占位块，保留图名、插入位置和证据说明 |

用户要求蓝色加粗时，仅设置颜色不算完成。同步后核对原生样式；特殊标记应被转换，截图或画板的插入提示则保留。已存在实际图片或画板时，不将其退化为占位文字。

## 授权后的局部交付

1. 先定位目标章节，读取最新内容与完整块结构，检查用户新改动及已有媒体。写作许可不代替文件或线上修改许可。
2. 小改动精确替换文字或目标块；新增说明使用对应锚点。保留其他章节与资源，不为局部修改重建整篇。
3. 结构重组前确认范围和可保留内容；版本变化时重新核对。替换或删除后重新获取受影响的块 ID，不沿用失效定位。
4. 使用对应平台技能或工具完成原生转换，按其最新文档处理接口限制；不要为绕过局部编辑失败扩大覆盖范围。
5. 回读核对本地与线上正文、标题层级、重点字重和颜色、分栏与表格、占位数量、媒体保留及重复插入情况。

总览与详述的内容核对也属于交付检查：总览简写结果，后文补充验证范围与依据，不能在同步时又恢复成重复报数。

## 检查层次

读取纯文本时，只能判断文字与部分结构。原生块信息可以核对标题、表格、字重和颜色，不能替代实际页面视觉检查。确实需要评估分栏、折叠状态、图中文字大小或窄屏效果，且符合用户意图与工具权限时，再查看真实页面或受支持的预览；只要求预留插图位置时不打开浏览器。

无法查看时明确未确认项，不声称“页面效果已验收”。区分写入成功、两端核对一致和用户认可正文，不将任一状态代替其他状态。

当普通段落和标题已能完成阅读任务时，保持简单。平台能力是否被充分使用不属于质量指标。
