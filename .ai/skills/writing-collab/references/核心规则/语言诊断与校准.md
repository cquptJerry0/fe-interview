# 语言诊断与校准

本页吸收 Human Signal 中适用于技术与工作文档的成因诊断、强度控制、低误报与保真检查，用于首稿和局部修稿。

## 生成前约定

从已有上下文整理作者、读者任务、体裁、载体和公开范围，选出必须保留的事实、数字、技术名称、条件与责任。只记录影响当前表达的项目。

读相关案例的背景、原稿、用户反馈、改稿和认可范围。原声样本学习句法、节奏、词汇、判断和分寸；用户只认可结构时，学习其组织关系。已明确的要求直接带入首稿，核心红线默认执行。

技术方案以关系、契约、动作和必要条件为主体；答辩以具体判断和个人增量为主；操作指南以能执行的入口、输入与结果为主。正式工整的语言可以保留，句长按信息量安排。

## 成因与动作

| 观察到的问题 | 先检查什么 | 修改动作 |
|---|---|---|
| 有观点却没有判断 | 读者要作什么决定、依据支持什么结论 | 提出有依据的建议及影响选择的条件 |
| 每节同一套路、解释平均铺满 | 各块目的、轻重和真实关系 | 重点展开，次要信息简述，共同原因说明一次 |
| 抽象词、套话、反面尾巴 | 原句具体对象、动作与新增信息 | 改成对象与行为，信息完整即结束 |
| 素材不足却显得具体 | 事实、默认值、效果是否有来源 | 补材料或保留准确缺口，措辞与证据相称 |
| 句间跳跃 | 是否换对象、是否缺条件或依赖 | 补真实关系，调整顺序 |
| 职业文档读成宣传稿或散文 | 读者任务、体裁和行业分寸 | 恢复技术对象、契约、动作和对应格式 |
| 原稿已经清楚 | 是否存在具体阅读障碍 | 保留原稿，修改有证据的问题位置 |

段落、编号、冒号、术语和否定按剂量、关系与语境判断。观察“密集而重复的功能”而非单个词是否出现。遵循主入口的正向陈述大红线，并保留确有作用的契约与风险。

## 改写强度

- **保留**：事实与关系清楚，读者任务达成，作者声音成立。
- **轻改**：结构保留，处理局部套话、指代、连接或冗余。
- **局部重组**：调整相关段落的轻重、分组与顺序，恢复缺失关系。
- **范围内重构**：核心阅读路径失效时调整已授权范围；用户限定局部则说明结构冲突再处理。

技术稿默认轻改。先定位具体障碍再决定强度，改动量与实际问题相称。案例的推荐稿是学习材料，事实与作者立场始终由本篇输入决定。

## 编辑意见与准出

每条意见写清“位置／原句、成因、动作、核对”。例如：第2段第二句重复前句职责；删除后对象、接口和条件完整。缺少原句位置或没有修改理由的意见不进入执行。

两项准出检查：
1. **保真**：事实、术语、条件、责任、数字、来源、风险与状态准确。遗漏或含义变化逐项恢复。
2. **阅读收益**：修改确实减少重复、补足关系或改善查阅，原有好表达与指定结构保持。

一轮检查后修复，再复核受影响内容。新证据或实质冲突才重新调查；稿件尚有具体缺口就写明影响。AI 味指数是主观编辑量尺，自动扫描只找候选，正文可用性由实际对照和读者验收判断。

## 对照试用

对同一材料比较当前首稿、加入前置约定的首稿、专项诊断后的修订稿。记录每个问题位置、事实保持、修改收益与用户认可范围。用自然好稿测试保留能力，用必要否定测试边界，用长文测试整体与局部一致。

Human Signal 专项仅按当前任务触发，其参考先完整读取。技术与工作文档优先采用成因、保真和尺度方法；本篇的术语、格式和原声是修稿依据。
