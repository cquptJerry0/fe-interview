# 代码输出题写法

适用范围：

1. `this`
2. 作用域链
3. 闭包输出题
4. 事件循环输出题
5. `Promise`、定时器、原型链等结果判断题

## 必讲四件事

1. 最终输出是什么
2. 规则是什么
3. 运行时为什么按这个规则取值
4. 为什么不是另一个常见错误答案

## 推荐结构

```txt
原始题干
原始代码

Part 1｜技术讲解
- 一句话结论
- 主链路图
- 运行时推导
- 最小反例
- 工程/业务例子

Part 2｜面试作答
- 思维导图关键点
- 60-90 秒口语稿
- 高频追问
```

## 关键提醒

1. 不要只报答案。
2. 不要只背名词。
3. 一定要点出最容易错的那个替代答案为什么错。
4. 默认保留原始题干和原始代码，不能只剩下结论。
5. 如果 `this`、作用域链、闭包、事件循环这几道题同时出现，优先把它们并到一个 `JS 底层` 总专题，而不是各写一篇浅稿。
6. `this` 类题至少讲清：调用方式、Reference 基对象是否丢失、箭头函数没有 own `this`、为什么 `call/apply` 只能改普通函数的动态绑定。
7. 作用域题至少讲清：词法作用域、Environment Record、`[[OuterEnv]]`、为什么调用位置改不了查找路径。
8. `Promise + setTimeout` 类题至少讲清：执行器同步、Promise Reaction Job、宿主微任务队列、当前任务结束后的 microtask checkpoint。
