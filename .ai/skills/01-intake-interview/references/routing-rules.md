# 题目路由规则

## 直接留在面经正文的题

满足下面任意一类，优先直接写进面经正文：

1. 单点定义题
2. 代码输出题
3. 轻量原理题
4. 轻量开放题
5. 轻量编程题

典型例子：

1. `this` 输出题
2. 作用域链输出题
3. `Promise + setTimeout` 顺序题
4. 闭包基础题
5. `pnpm` 为什么更好
6. 反转链表

## 必须抽专题的题

同时满足下面大部分条件时，抽专题：

1. 能形成完整知识链
2. 至少串起 3 个以上知识点
3. 明显值得多次复用
4. 继续追问时深度很高
5. 简单短答无法承载真实价值

典型例子：

1. 输入 URL 到页面显示
2. 浏览器渲染流水线
3. RenderNG / Viz
4. SSR 全链路
5. JS 执行机制全链路
6. React 渲染与调度
7. `pnpm` 幻影依赖原理

## 默认判断原则

1. 简单题留正文。
2. 系统题抽专题。
3. 正文只承担入口功能，不承担完整知识沉淀。
