# 归档与画像 SOP

## 一篇面经过完后要做什么

1. 把会话归档到 `02-训练会话/02-已归档/`
2. 把新知识或补强内容写进 `03-题库/`
3. 按 tag 更新 `04-画像与复习/01-熟练度画像/`
4. 更新复习索引和本周复习清单
5. 把变化写入归档日志

## 画像更新至少记录什么

- 哪些 tag 已掌握
- 哪些 tag 仍需复习
- 哪些题主回答还不稳定
- 哪些题能画出原理图，哪些题画不出来
- 哪些题追问能接住，哪些题一追就断
- 哪些题总是缺例子 / 缺取舍 / 缺排障
- 哪些题需要“加厚版输出”才能讲明白
- 哪些题属于：`标准版可掌握`、`加厚版后可掌握`、`仍需专题深挖`
- 哪些题可以快答，哪些题必须深讲
- 哪些题需要补专题深挖卡
