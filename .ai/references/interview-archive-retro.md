# Interview Archive Retro Reference

用于在“完整面经训练结束后”一次性落盘资产。

## 最小输入

- 公司/部门/岗位/轮次/日期
- 原始题目列表与来源
- 每题最终答案与 tags
- 掌握度分类（unknown/new_learned/need_review/mastered）

## 必达输出

1. 原始面经入口  
   `01-内容库/01-原始题单/07-公司面经-原始材料/按公司/<公司>/<日期>-<轮次>.md`
2. 满分回答条目  
   `01-内容库/02-知识条目/02-满分回答库/01-模板化回答（可背）/*.md`
3. 导航更新  
   `03-导航/00-总导航.md`  
   `03-导航/01-按Tag索引.md`  
   `03-导航/02-按公司索引.md`  
   `03-导航/03-按模块索引.md`  
   `03-导航/04-本周复习清单.md`
4. 训练记录更新  
   `02-训练记录/02-训练会话/YYYY-MM/*.md`  
   `02-训练记录/01-熟练度画像/profile.yaml`  
   `02-训练记录/03-归档日志（可统计）/mastery-history.jsonl`

## 执行步骤

1. 补齐 tags：更新 `.ai/schemas/tags.yaml`
2. 生成知识条目：按 `.ai/templates/06-知识条目.template.md`
3. 生成原始面经入口：每题追加“满分回答链接”
4. 更新导航：按公司/模块/Tag/本周复习
5. 更新记录：会话 + 画像 + jsonl

## 质量门禁

- 链接可达且无 ``
- 画像与 jsonl 可解析
- unknown/need_review 有下次复习建议
