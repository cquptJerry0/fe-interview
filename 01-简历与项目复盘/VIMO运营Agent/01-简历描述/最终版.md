# VIMO 智能运营 Agent

## 项目简介

VIMO 智能运营 Agent 面向素材管理、资源位配置和活动配合等运营场景，将自然语言需求转化为可执行、可追踪的跨系统查询、批量操作与运营流程。

## 技术栈

`TypeScript/Node.js、DeepAgents（基于 LangGraph）、OeFlow、Sandbox、OpenAPI/vimocli、JSON Schema、MySQL`

## 重点贡献

### 1. 素材任务编译与执行分流

负责素材管理 SubAgent 的任务解析与执行分流，将运营需求转换为包含素材范围、目标动作、站点约束和完成条件的任务计划，并通过只读查询补全真实业务状态；简单查询即时执行，同构批量进入 Batch Runner，包含审批或 Callback 等外部等待的任务交由 OeFlow 持久运行。

### 2. 素材能力动态装配

在素材 SubAgent 中接入查询、上传、迁移、打标、分级和状态变更等 OpenAPI/vimocli 操作，统一补充参数 Schema、适用站点和版本约束；运行时按任务上下文装载候选 Capability，使新增操作无需修改 Agent 主流程。

### 3. 批量素材确定性执行

将批量打标、迁移和状态治理从逐素材 Tool Calling 改为一次 BatchPlan，由 Batch Runner 在 Sandbox 内完成分片、并发控制、背压和对象级结果汇总；模型只负责生成计划，Runner 按固定规则执行对象循环，并对明确失败素材生成精确重跑集合。

### 4. 素材变更安全与结果闭环

基于平台统一 Invoker 完善素材变更链路，执行前校验用户与站点上下文、素材集合和最大影响范围，并锁定运营确认的对象版本。每次变更分配 operationId，遇到超时或未知结果时先回查真实素材状态，只重试确认失败项，避免重复写入。

### 5. 素材任务评测与失败回放

将任务理解、Capability 选择、计划生成、工具执行和业务回查串联到同一 Run Trace，以真实素材状态判断任务是否完成，并把线上失败按阶段沉淀为回放样本，用于定位问题和回归高频素材任务。

## 项目收益

覆盖`[X]`类素材运营任务与`[Y]`条高频 SOP，典型任务人工步骤由`[A]`降至`[B]`，业务完成率达到`[C]%`；批量任务可定位到具体失败素材，超时和未知结果可通过业务回查闭环。

> 数字占位符需要使用真实统计回填；无法回填时，删除对应数字，不改写为无口径的百分比。
