# VIMO 智能运营 Agent

> 更新日期：2026-08-17
>
> 当前目录只保留最新研究结论，不维护历史草稿和重复故事书。

## 项目简介

```text
VIMO 智能运营 Agent 面向素材管理、资源位配置和活动配合等运营场景，
将自然语言需求转化为可执行、可追踪的跨系统查询、批量操作与运营流程。
```

## 个人模块

本项目材料聚焦候选人负责的`素材管理 SubAgent`，主要覆盖：

```text
素材任务理解与执行分流
素材能力接入与动态装配
批量素材确定性执行
素材变更安全与结果闭环
素材任务评测与失败回放
```

DeepAgents/LangGraph、OeFlow、统一 IAM、业务服务和 A2UI 属于团队或上游基座。个人贡献只描述素材管理 SubAgent 内的任务链路、能力接入、批量执行和评测工作。

## 使用规则

1. 项目简介只介绍 VIMO Agent 的业务，不塞入个人职责和技术模块。
2. 重点贡献统一以素材管理 SubAgent 为个人范围。
3. 素材、面板和实验属于素材管理模块中的对象与流程，不作为一级业务并列。
4. 素材搬运可以作为综合 Case，但不能代替素材管理 SubAgent 的全部职责。
5. 最终简历只选择两到三个有真实统计口径的数字。
