# VIMO 素材 OpenAPI / CLI 平台化：业务与技术背景

## 业务背景

VIMO 是面向视频编辑器素材生产与分发的内部管理平台，管理素材、资源包、分级、面板、分类、实验和发布等核心对象。

原有运营能力主要通过 Web 后台提供，程序化调用方需要重复理解页面接口、身份上下文、资源权限和操作顺序，因此需要建设稳定、可治理的开放能力体系。

## 整体链路

```text
业务能力
  → OpenAPI 契约
  → ByteCloud Gateway
  → JWT / Service Account
  → 接口权限与资源权限
  → vimocli 标准执行入口
```

## 业务范围

当前主要覆盖素材、分级、面板、实验和发布等运营场景。

## 时间线与指标

当前指标口径包括 40+ OpenAPI、累计用户 90+、月均 UV 50+、月均 PV 5 万+、5+ 重点业务链路，以及素材生产单季度通过 OpenAPI 入库素材 2 万+。具体去重方式和统计周期后续继续补充。
