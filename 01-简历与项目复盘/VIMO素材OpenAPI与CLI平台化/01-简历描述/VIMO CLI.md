# VIMO CLI

## 项目简介

负责 VIMO CLI 从 0 到 1 建设，将原本依赖 Web 后台的核心运营能力沉淀为标准 OpenAPI，并以 CLI 作为人工、脚本与 Agent 的统一执行入口，打通业务接入、命令交付与 Agent 使用链路。

## 核心贡献

1. 多模式接入与分层权限：设计统一接入中间件，兼容 Gateway、个人 JWT 与 Service Account，并按接口分流 OpenAPI 资源级授权与 Kani 功能鉴权；OpenAPI 侧通过独立集群、单用户 QPS 及 Path、素材类型、面板多级权限实现流量隔离与细粒度管控，支持后续业务快速接入。

2. CLI 工程化：

命令生成内核：设计“生成层 + 领域层”双层命令模型，由 BAM/IDL 生成 Client 与基础命令，领域层维护稳定业务语义，解决全手写扩展成本高与直接生成暴露后端 Contract 的矛盾，支撑 50+ OpenAPI 持续扩展。

客户端自更新：设计“版本检测、安装方式识别、自动升级、Skill 同步”链路，解决接口、CLI 与使用知识的版本漂移，降低人工升级与旧版本兼容成本。

3. Skill 设计与评测：按照“统一入口路由、领域 Sub-Skill 承载完整任务”的思路重构 Skill，并围绕路由、参数补全、命令执行和结果回读构建端到端评测，以最终业务状态判定任务闭环，首轮闭环率由 68% 提升至 91%。

## 项目收益

Q2 覆盖国内外用户 70+，相对 30 人目标达成率 233%+；素材生产单季度通过 CLI 入库 2 万+
