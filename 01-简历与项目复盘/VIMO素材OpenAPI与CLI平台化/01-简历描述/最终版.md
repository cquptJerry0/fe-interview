# VIMO 素材 OpenAPI / CLI 平台化

## 项目简介

从 0 到 1 建设 VIMO 素材开放体系，将原本依赖 Web 后台的核心运营能力沉淀为标准 OpenAPI，并以 `vimocli` 提供统一执行入口，打通 Gateway、身份认证与资源权限治理，支撑素材、分级、面板、实验及发布等场景的程序化调用。

## 核心贡献

1. 领域命令编译器：将 GUI 中依赖页面状态与多接口编排的运营操作重构为稳定 OpenAPI 契约，统一处理参数语义、默认值、状态流转与上下游数据转换；基于 BAM / IDL 生成类型化 Client、参数 Schema 与基础命令，并以领域命令层隔离接口结构和用户语义。
2. 声明式运营任务：设计 Task DSL，将多步骤运营流程编译为依赖 DAG，通过静态类型校验、步骤输出引用和模板版本管理，将分散的临时脚本沉淀为可复用、可评审的流程模板，覆盖 5 类核心运营场景。
3. 工程化设计：
   - 自动发布：针对多人手工发版易冲突的问题，基于 MR 合并事件自动完成校验、版本计算、Tag 与 bnpm 发布，将发版收敛为标准流程。
   - Skill 工程化：使用侧由统一入口按任务意图路由单个领域 Sub-Skill，统一命令选择、参数约束与操作边界；研发侧将需求、OpenAPI、Codegen 和测试发布按阶段编排，形成可校验、可追踪的跨仓交付流程。
   - 版本治理：面向用户版本分散，通过版本检测、自更新、升级后重执行与 Skill 同步，保持 CLI、接口契约与使用知识一致。

## 项目收益

沉淀 50+ OpenAPI，累计用户 90+，月均 UV 50+、PV 5 万+；支持 5+ 重点业务链路，其中素材生产单季度通过 CLI 入库素材 2 万+。
