# raw 原材料区

raw 只放原材料，目标是可追溯，不是可复习。

## 子目录

- [mianjing](mianjing/)：面经来源。
- [learning-sources](learning-sources/)：文章、视频、官方文档等学习来源。
- [old-notes](old-notes/)：旧索引、旧笔记和暂时不直接进入主系统的历史材料。

## 写法模板

```text
# 标题

## 来源

## 日期

## 类型

面经 / 文章 / 视频 / 旧笔记 / 官方文档

## 原文或摘录

## 我提取到的问题

## 可能归属

八股 / 手写 / 项目

## 备注
```

## 边界

raw 里不写完整答案。

完整答案、口述模板、手写实现和项目追问必须进入主系统。
