## 这题在问什么

不只是问你会不会写 `text-overflow: ellipsis`，更是在问：
- 单行和多行的写法分别是什么
- 为什么 flex 布局里常常不生效
- 你有没有踩过 `min-width: 0` 这种真实坑

## 60 秒直答

单行省略的标准写法是 `overflow: hidden`、`white-space: nowrap`、`text-overflow: ellipsis` 三件套。多行省略在 Web 场景最常见的是 `display: -webkit-box`、`-webkit-line-clamp`、`-webkit-box-orient: vertical`。如果在 flex 子项里不生效，通常不是 ellipsis 写错了，而是子项默认 `min-width: auto`，这时要补 `min-width: 0` 才能真正收缩。

## 核心机制

- 省略号的前提是“内容真的发生了溢出”
- 单行场景靠禁止换行来制造溢出
- 多行场景靠行数裁剪
- flex 场景下如果子项不能收缩，就根本不会溢出，自然看不到省略号

## 最小例子

```css
.single-line {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

.multi-line {
  overflow: hidden;
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2;
}

.flex-child {
  min-width: 0;
}
```

## 业务 / 验证

真实项目里最常见的坑是标题在 flex 布局里怎么都不省略。验证思路很简单：打开 DevTools 看这个元素的实际宽度是否被压缩，如果没被压缩，先查父级和子级的 flex 设置，再看 `min-width`。

## 常见追问

- 多行省略兼容性不好时怎么办？
- 为什么 `width: 100%` 也可能不生效？
- grid 布局下是否也会遇到类似问题？
- 如果文本要支持 tooltip，应该什么时候展示？

## 易错点

- 少写单行三件套中的任意一个
- 只会背多行写法，但解释不了为什么它生效
- 不知道 flex 子项默认 `min-width: auto`
