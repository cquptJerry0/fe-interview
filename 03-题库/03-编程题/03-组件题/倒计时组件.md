## 题目与边界

实现一个倒计时组件：
- 输入：目标时间戳 `targetMs`
- 输出：剩余秒数
- 行为：倒计时结束后显示 `0`，并触发 `onFinish`

面试时默认先做最小可跑版本，不追求复杂展示样式。

## MVP 思路

最小可跑版本只需要 2 件事：
- 用状态保存当前时间 `now`
- 用 `targetMs - now` 算出剩余秒数

副作用部分用 `useEffect` 建定时器，组件卸载时清理定时器，避免泄漏。

## 代码

```tsx
import { useEffect, useMemo, useRef, useState } from 'react'

type CountdownProps = {
  targetMs: number
  onFinish?: () => void
}

export function Countdown({ targetMs, onFinish }: CountdownProps) {
  const [now, setNow] = useState(() => Date.now())
  const finishedRef = useRef(false)

  const leftSeconds = useMemo(() => {
    const leftMs = Math.max(0, targetMs - now)
    return Math.ceil(leftMs / 1000)
  }, [now, targetMs])

  useEffect(() => {
    if (leftSeconds <= 0) return

    const timerId = window.setInterval(() => {
      setNow(Date.now())
    }, 250)

    return () => window.clearInterval(timerId)
  }, [leftSeconds])

  useEffect(() => {
    if (leftSeconds !== 0 || finishedRef.current) return
    finishedRef.current = true
    onFinish?.()
  }, [leftSeconds, onFinish])

  return <span>{leftSeconds}</span>
}
```

## 复杂度

- 时间复杂度：每次 tick 是 `O(1)`
- 空间复杂度：`O(1)`

## 最小用例

- `targetMs` 在未来 10 秒：数字递减到 0
- `targetMs` 已经过期：初始就显示 0
- 组件卸载：定时器被清理
- `onFinish`：只触发一次

## 面试时怎么讲

我会先做一个最短可跑版：状态里放 `now`，每隔一小段时间刷新一次，然后通过 `targetMs - now` 算剩余秒数。副作用核心在定时器管理：倒计时结束后要停，组件卸载时要清理，`onFinish` 只能触发一次。这个版本先保证正确，再根据时间补格式化展示、只在秒变化时更新、以及把时间计算抽成纯函数方便测试。

## 可选加分点

- 展示层补成 `mm:ss`
- 只在秒变化时更新，减少重渲染
- 抽出 `getLeftSeconds` 纯函数，便于测试
- 解释 `useEffect`、清理函数、定时器精度这些追问
