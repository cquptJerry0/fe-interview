# 面试准备

这个仓库只保留四个真正会使用的内容区域。

## 目录

1. [简历与项目复盘](01-简历与项目复盘/)
2. [高收益八股](02-高收益八股/)
3. [Agent 与 Codex](03-Agent与Codex/)
4. [高收益手写题](04-高收益手写题/)

## 使用方式

1. 简历内容按项目维护，每个项目只分为 `01-简历描述` 和 `02-具体内容`。
2. 八股与手写题只保留值得重复复习的正文，不提前创建空知识目录。
3. Agent、CLI、MCP、Skill 和 AI Coding 知识统一放在 `03-Agent与Codex`。
4. 近期要做和已经完成的内容统一维护在 [待办](待办.md)。
5. AI 专用工作流位于 `.ai/skills`，仓库规则位于根目录 `AGENTS.md`，不占用复习目录。
