# 秋招上场系统

这个 workspace 用来维护秋招备战的上场系统。

核心判断只有一个：

```text
这个内容现在能不能上考场？
```

## 系统分工

- Git 内容区：维护真正要复习、口述、手写、项目表达的正文。
- 飞书多维表格：维护状态、优先级、下一步动作和 Git 文件路径。

不要在飞书和 Git 里同时维护正文内容。

## 三条线

- 八股线：概念、原理、高频问答和 408 基础。
- 手写线：JS 手写、React 手写和 LeetCode 题型。
- 项目线：AI 项目、后端、数据库、Redis、Hive、工程设计和项目故事线。

## 两种状态

- 未上场：没学过、讲不顺、写不出、答不完整。
- 可上场：能用自己的话讲清楚，能举例，能接基础追问。

## 主目录

- [raw](raw/README.md)：原材料区，只放来源和摘录，不写完整答案。
- [bagu](bagu/index.md)：八股主系统。
- [coding](coding/index.md)：手写主系统。
- [project](project/index.md)：项目表达主系统。
- [tracker](tracker/README.md)：唯一主表和后续飞书同步真源。
- [specs](specs/00-overview.md)：系统规则和调研约束。
