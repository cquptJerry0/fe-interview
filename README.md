# fe-interview

这是一个按“面经输入 → 逐题训练 → 缺失深挖建档 → 画像复习”组织的前端面试训练仓库。

## 先看哪里

- 人类入口：[00-使用说明.md](00-使用说明.md)
- 当前会话看板：[02-训练会话/01-进行中/00-当前会话看板.md](02-训练会话/01-进行中/00-当前会话看板.md)
- 题库总入口：[03-题库/00-题库说明.md](03-题库/00-题库说明.md)
- 复习总览：[04-画像与复习/02-复习索引/00-总览.md](04-画像与复习/02-复习索引/00-总览.md)

## 顶层结构

- `01-面经输入/`：放面经原文和专题题单
- `02-训练会话/`：放当前进行中的会话和历史归档
- `03-题库/`：放内部自洽的知识卡、标准答案、编程题和 Demo
- `04-画像与复习/`：放熟练度画像、复习索引和归档日志
- `.ai/`：AI 运行时配置
- `99-维护说明/`：迁移说明、验收用例等维护资料

## 这次重构的核心原则

- 对你暴露的主线只有一条：`导入面经 -> 一题一题过 -> 归档 -> 更新画像`
- 题库必须内部自洽；仓里没有的知识点，先深挖建档，再继续过题
- 目录按工作流组织，而不是按“原材料/记录/导航”这种存储视角组织
