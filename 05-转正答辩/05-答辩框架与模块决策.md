### 2.1 业务理解

> [!NOTE]
> VIMO 素材模块提供素材管理与素材供给能力：素材管理涵盖素材本身及实验、资源包、版权和策略，素材供给维护素材与业务线、面板、分类的配置关系。

#### 素材管理与素材供给

```text
[素材管理]                                  [素材供给]
  |                                           |
  +-- 素材本身                                +-- 业务线
  |   ID / 类型 / 文件 / 基础属性                   |
  |                                                 +-- 面板
  +-- 素材相关能力                                       |
      +-- 实验                                           +-- 分类
      +-- 资源包                                             |
      +-- 版权                                               +-- 素材关联
      +-- 策略

      素材本身 ............ 引用同一素材 ............ 素材关联
                                                        |
                                              配置调整、验证与发布
                                                        v
                                                 客户端展示与使用
```

1. 左侧说明素材本身及相关业务能力，右侧说明素材在业务中的配置关系。
2. 右侧树形结构表示业务线、面板、分类的配置组织视角，不表示请求执行顺序。
3. 点线表示供给配置引用素材，不表示复制文件或创建另一份素材。
4. 底部箭头单独表示供给配置的调整、验证发布与客户端使用。

#### 素材管理

1. 素材本身。
   - 管理素材文件、类型和基础属性等信息。
2. 素材相关能力。
   - 管理实验、资源包、版权、策略等业务内容。
3. 使用条件。
   - 版权、合同和授权记录允许使用的范围。
   - 免费、订阅、限免等商业化策略描述产品内的使用权益。

#### 素材供给

1. 业务关系。
   - 维护素材与业务线、面板和分类的配置关系。
   - 明确素材在哪个业务、面板和分类中使用。
2. 配置维护。
   - 素材本身的信息与它在面板分类中的配置分别维护。
   - 业务、地区和版本等差异体现在对应配置中。
3. 配置生效。
   - 分类编排、自动分发等操作维护素材的供给关系。
   - 验证与发布负责让对应配置在目标业务中生效。
