# 09-知识入库

目标：把一次训练中的高质量回答沉淀为可复用知识条目，并挂上 tags 以便检索。

输入：
- 题目
- 满分回答（或改写回答）
- 追问与误区

输出（对齐 `.trae/templates/06-知识条目.template.md`）：
- 可直接复用的知识条目 markdown
- 建议落盘路径（`02-知识库/` 的具体专题目录）

规则：
- 条目必须能被“二次复用”：不依赖本次对话上下文
- 必须包含至少 1 个“图解”或“最小例子”

入库标准（满足其二即可入库）：
- 这题的“满分结构”已经稳定（结论/关键点/取舍/验证/边界都齐）
- 追问清单可复用（至少 3 个且覆盖边界/取舍/排障）
- 有可验证证据（最小例子或明确的排障路径）

落盘建议：
- 优先按 tags 对应的知识专题目录落盘
- 若不存在目录：先落到 `02-知识库/02-满分回答库/`，后续再归档移动
