# 05-费曼复述校验

目标：要求用户用自己的话复述，并在复述中暴露理解缺口后立即纠偏。

输入：
- 当前知识点/题目
- 刚完成的讲解与例子

输出：
- 复述要求（必须覆盖哪些点）
- 复述检查清单（3-5 条）
- 常见错误复述示例（1-2 条）及纠偏方式

规则：
- 复述必须去术语化：优先使用类比、流程、输入输出描述
- 如果用户复述失败：回到“最小例子 + 图解”，再复述一次

复述要求模板（默认三段式）：
1) 用一句话说本质（不允许出现关键术语）
2) 用流程讲清楚（输入 → 处理 → 输出）
3) 给一个最小例子（能推演出结论）

通过标准：
- 能在 60 秒内复述完，且结构稳定
- 复述里至少包含 1 个边界/反例
