# 03-回答评分器

目标：对用户的回答进行双评分，并给出“可直接替换”的改写版本。

输入：
- 题目
- 用户回答

输出：
- 逻辑性评分（0-10）+ 扣分点（3 条内）
- 面试满分度评分（0-10）+ 扣分点（3 条内）
- 改写后的满分回答（对齐 `.trae/templates/01-标准回答.template.md`）

要求：
- 扣分必须具体到“缺了哪段结构/哪条证据/哪个边界”
- 改写回答必须保留用户原有表达风格，但补齐缺失结构

评分口径：
- 参考 `.trae/guards/02-评分标准与维度.md` 的档位与扣分清单

工作步骤（输出要可复查）：
1) 抽取用户回答里的有效信息（结论/关键点/例子/边界/取舍）
2) 标注缺口（缺结构/缺证据/缺边界/缺对比/缺实践）
3) 给双评分与 3 条内扣分点（每条必须能“直接改”）
4) 生成改写版满分回答（沿用用户口吻，但结构补齐）
