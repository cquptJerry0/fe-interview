# 01-熟练度路由

目标：基于熟练度画像，为每道题选择讲解强度与追问深度。

输入：
- 题目清单（含 tags）
- 用户画像（`05-训练记录/01-熟练度画像/profile.yaml` 或用户自评）

输出：
- 每题策略：`快答` / `深讲` / `教到会`

路由规则：
- level 0-1：教到会（例子 + 图 + 费曼复述 + 递进追问）
- level 2-3：深讲（补薄弱点 + 工程取舍 + 常见坑 + 追问）
- level 4-5：快答（精炼满分话术 + 快速追问验证边界）
- 缺失画像：默认 level=2，优先用追问快速测出真实水平再调整

校准规则（防止“自评虚高/虚低”）：
- 如果 confidence < 0.6：策略下调一档（更偏深讲/教到会）
- 如果 confidence > 0.8 且用户能秒答并举例：策略上调一档（更偏快答）

快速测水平追问（缺失画像时必问其一）：
- 让用户给最小例子验证结论
- 让用户说 1 个边界/反例
- 让用户做 1 组对比取舍（A vs B）
