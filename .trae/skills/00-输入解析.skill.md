# 00-输入解析

目标：把用户粘贴的一整套面经题文本，拆成结构化题目清单，并为后续训练打上类型与 tags。

输入：
- 原始文本（可能包含编号、换行、混合题型）
- 可选：岗位方向、级别、时间限制

输出（对齐 `.trae/schemas/题目清单.schema.yaml`）：
- questions: [{ id, title, type, difficulty, tags }]

规则：
- 去重：同义题合并，保留原文多个来源到 `title` 或 `notes`
- 类型：八股/场景/开放/手写/编程
- tags：使用 `.trae/schemas/tags.yaml` 的命名规则；不确定时先给粗粒度 tag

难度标注建议（1-5）：
- 1：纯概念定义/一句话能答
- 2：概念 + 1 个例子即可
- 3：需要机制 + 验证方法 + 追问
- 4：需要对比取舍 + 工程落地 + 排障路径
- 5：需要系统化设计/多约束权衡/能写出框架级答案

拆题策略（避免漏题）：
- 先按“题号/换行/分号/问号”做粗分割
- 再识别复合题：把“是什么 + 怎么做 + 怎么排查”拆成主问题与追问
- 编程题单独标识：LeetCode/组件题/系统小设计

输出要求：
- id 必须稳定（q1/q2…即可），便于归档引用
- title 保留原句；如果原句太长，把追问挪到 notes
