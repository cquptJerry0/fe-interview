# 00-输入解析

目标：把用户粘贴的一整套面经题文本，拆成结构化题目清单，并为后续训练打上类型与 tags。

输入：
- 原始文本（可能包含编号、换行、混合题型）
- 可选：岗位方向、级别、时间限制

输出（对齐 `.trae/schemas/题目清单.schema.yaml`）：
- questions: [{ id, title, type, difficulty, tags }]

规则：
- 去重：同义题合并，保留原文多个来源到 `title` 或 `notes`
- 类型：八股/场景/开放/手写/编程
- tags：使用 `.trae/schemas/tags.yaml` 的命名规则；不确定时先给粗粒度 tag
