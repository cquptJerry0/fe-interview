# 08-模块归档

目标：每个模块结束后输出归档，形成“会话记录 + 画像更新建议 + 可统计日志”。

输入：
- 本模块题目列表
- 用户答题表现（评分、暴露的缺口）

输出（对齐 `.trae/templates/05-模块归档.template.md`）：
- unknown / new_learned / need_review / mastered（按 tags 列表）
- 熟练度更新建议（tag -> level/confidence 变化）
- 可追加日志行（jsonl）

规则：
- unknown 与 need_review 优先生成“下次复习建议”（最少 1 句话）
- jsonl 日志不写隐私信息，只写 tag、delta、证据摘要

分类建议（按表现落位）：
- unknown：用户无法给出一句话结论，或概念明显错误
- need_review：主流程能讲，但缺“例子/边界/取舍/排障”任一关键块
- new_learned：本次补齐并能复述，但仍需要巩固（通常 confidence < 0.8）
- mastered：能稳定口述 + 能接住 2 个追问（通常 confidence ≥ 0.8）

jsonl 建议字段（最小集合）：
- date
- module
- tag
- delta_level（可选）
- delta_confidence（可选）
- evidence
- session
