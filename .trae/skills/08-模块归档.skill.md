# 08-模块归档

目标：每个模块结束后输出归档，形成“会话记录 + 画像更新建议 + 可统计日志”。

输入：
- 本模块题目列表
- 用户答题表现（评分、暴露的缺口）

输出（对齐 `.trae/templates/05-模块归档.template.md`）：
- unknown / new_learned / need_review / mastered（按 tags 列表）
- 熟练度更新建议（tag -> level/confidence 变化）
- 可追加日志行（jsonl）

规则：
- unknown 与 need_review 优先生成“下次复习建议”（最少 1 句话）
- jsonl 日志不写隐私信息，只写 tag、delta、证据摘要
