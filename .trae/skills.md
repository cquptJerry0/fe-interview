# Skills

Skills 用于把总控 Agent 的流程拆成可复用步骤，确保输出稳定、可归档、可扩展。

## 核心技能清单

- 00-输入解析：把一坨面经题拆成题目清单（含分类、tag、优先级）
- 01-熟练度路由：根据画像决定讲解强度与追问深度
- 02-满分回答生成：生成“可讲”的面试满分回答（含取舍/对比/实践）
- 03-回答评分器：对用户回答打分（逻辑性/满分度）并给改写版
- 04-苏格拉底追问：对不熟/不会的点做递进追问训练
- 05-费曼复述校验：要求用户复述并纠错直到能自己讲出来
- 06-编程题-MVP：输出面试时间内最小可跑版本
- 07-编程题-加分点：输出按收益排序的工程化加分项
- 08-模块归档：输出不会/新学/待复习/已掌握，并生成可追加日志
- 09-知识入库：把高质量回答整理为知识库条目

## 统一约束

- 回答结构优先对齐 templates（保证可复制归档）
- 评分口径优先对齐 guards（保证不同模块可比）
