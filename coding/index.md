# 手写线

手写线负责现场编码能力。

目标不是收藏题解，而是形成能现场写、能口述、能处理边界的题型库。

## 模块

- [js](js/index.md)：JS 高频手写。
- [react](react/index.md)：React 高频手写。
- [leetcode](leetcode/index.md)：LeetCode 高频题型。

## 题型页模板

```text
# 题型标题

## 题型定位

这类题考什么。

## 核心思路

现场怎么推。

## 标准实现

代码。

## 口述模板

边写边怎么说。

## 边界情况

哪些 case 容易漏。

## 变体

面试可能怎么改题。

## 错点

我自己容易错在哪里。

## 来源

raw 或面经来源。
```

## 可上场标准

- 能不看答案写出核心实现。
- 能解释关键步骤。
- 能处理主要边界。
- 能说出至少一个变体。
