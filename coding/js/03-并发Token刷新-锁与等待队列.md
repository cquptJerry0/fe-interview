# 并发 Token 刷新：锁与等待队列

## 题型定位

并发请求下的 Token 过期刷新与请求重放题。

## 核心思路

用一个刷新锁保证同一时间只有一个刷新请求；其他失败请求进入等待队列，刷新成功后统一重放，刷新失败后统一失败并清空队列。

## 边界情况

- 刷新失败时不能让队列永久等待。
- 重放请求要避免无限刷新。
- 队列清理需要覆盖成功和失败路径。
