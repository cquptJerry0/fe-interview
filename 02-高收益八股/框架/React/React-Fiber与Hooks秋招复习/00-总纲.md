# React Fiber 与 Hooks 秋招复习总纲

## 一、复习目标

这套复习面向秋招 React 面试，不按 API 或零散术语背诵，而是围绕一次真实更新的完整链路建立统一心智：

```text
用户事件
  ↓
setState 创建更新
  ↓
更新进入 Hook 队列
  ↓
Lane 表达更新优先级
  ↓
调度 Fiber Root
  ↓
Render 阶段计算新 Fiber 树
  ↓
Commit 阶段应用页面变更
```

最终需要达到三个层次：

1. 能用最简心智解释 React 的常见行为。
2. 能沿 Fiber、Hook 和 UpdateQueue 讲清底层机制。
3. 能回答源码追问、判断输出，并处理常见线上问题。

## 三、版本口径

1. 稳定心智以 React 18 以来的并发架构、自动批处理和 Hooks 模型为主。
2. 源码分析固定参考 `react@19.2` 标签，不跟随 `main` 分支函数名和字段变化。
3. React 19 新能力作为现代 React 加分题，不挤占 Fiber、协调过程、Hooks 和调度机制的主干篇幅。
4. `Fiber`、`Hook`、`Lane` 等属于 React 内部实现，不将具体字段和函数名描述成稳定公共 API。
5. 遇到历史版本差异时，明确区分 React 17、React 18 和 React 19 的行为，不混用结论。
